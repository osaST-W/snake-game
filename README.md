# 🐍 Змейка на Python (Snake Game)

Классическая игра "Змейка", написанная на чистом Python с использованием библиотеки `tkinter`.

## 🎮 Особенности
- Полностью на стандартной библиотеке Python (не требует сторонних зависимостей).
- Поддержка управления клавиатурой (`WASD` и стрелки `↑ ↓ ← →`).
- Подсчёт очков и сохранение рекорда за сессию.
- Кнопка паузы (пробел) и быстрого перезапуска (`R`).
- Плавное ускорение игры по мере поедания яблок.

## 🚀 Запуск
```powershell
python snake.py
```
